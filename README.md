# Gates API

ASP.NET Core Web API для проверки кодов доступа к воротам.

## Запуск

```bash
dotnet run --project Gates
```

- API: `http://localhost:5069`
- Swagger UI: `http://localhost:5069/swagger`
- OpenAPI JSON: `http://localhost:5069/swagger/v1/swagger.json`

## Endpoint

### `POST /api/gates/validate`

Проверяет код доступа и возвращает результат со списком **всех** обнаруженных нарушений.

Запрос:

```json
{
  "accessCode": "Dragon7!"
}
```

Успешный ответ — `200 OK`:

```json
{
  "isValid": true,
  "errors": [],
  "message": "Код принят. Ворота открываются."
}
```

Ответ с нарушениями — `200 OK`:

```json
{
  "isValid": false,
  "errors": [
    "Нет заглавной латинской буквы.",
    "Нет специального символа.",
    "Обнаружена последовательность из трёх или более подряд идущих цифр."
  ],
  "message": "Код отклонён."
}
```

Если код не передан, пуст или состоит только из пробелов — `400 Bad Request`:

```json
{
  "isValid": false,
  "errors": ["Код доступа не передан или пуст."],
  "message": "Некорректный запрос: код доступа отсутствует или пуст."
}
```

Некорректный JSON в теле запроса также возвращает `400 Bad Request` (ProblemDetails от ASP.NET Core).

Код, который не соответствует правилам, — это валидный запрос, поэтому возвращается `200 OK`
с `isValid: false`; статус `400` зарезервирован для некорректного запроса.

## Правила проверки

Код считается корректным, только если выполнены все условия:

1. Длина — от 8 до 16 символов включительно.
2. Есть хотя бы одна заглавная латинская буква (`A–Z`).
3. Есть хотя бы одна строчная латинская буква (`a–z`).
4. Есть хотя бы одна цифра (`0–9`).
5. Есть хотя бы один специальный символ из набора `!`, `@`, `#`, `$`, `%`.
6. Нет пробелов.
7. Нет трёх одинаковых символов подряд.
8. Нет последовательностей из трёх и более подряд идущих цифр.
9. Первый символ — латинская буква.
10. Последний символ — цифра или разрешённый специальный символ.

Проверяются все правила сразу, поэтому в `errors` попадают все нарушения, а не только первое.

## Структура

```
Gates/
  Controllers/GatesController.cs        — HTTP endpoint
  Models/                               — DTO запроса и ответа
  Services/IAccessCodeValidator.cs      — контракт бизнес-логики
  Services/AccessCodeValidator.cs       — правила проверки
  Services/AccessCodeValidationResult.cs
```

Сервис `IAccessCodeValidator` зарегистрирован в DI как singleton, контроллер не содержит логики проверки.
